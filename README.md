# paineisValim-loterias
Genera combinaciones permitiendo elegir cuántos números —ya sean sorteados con frecuencia, atrasados, nunca sorteados o repetidos del último sorteo— incluir, además de considerar números pares, primos, la suma, pares y tríos frecuentes, así como números fijos o excluidos. Cada combinación muestra su mejor resultado histórico.
